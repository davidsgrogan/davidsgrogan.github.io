Test: a button inside role=menu

All three menus have the same items. They differ only in where the Share… button is and whether the arrow keys reach it.

Keyboard: on a File button, press Enter, Space or Down Arrow to open the menu. In the menu: Up/Down Arrow, Home and End move focus; Escape closes the menu and returns focus to File; Tab closes it and moves on.

Things to note in each screen reader: does it announce the button when focus lands on it, does it still say it's in a menu, what is the "X of Y" count, and can the virtual cursor (browse mode) reach the button?
