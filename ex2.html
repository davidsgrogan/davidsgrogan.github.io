Menubar with Submenus

This is a horizontal menubar containing several top-level submenus (File, Edit, View, Help). Clicking these opens a dropdown list of menu items.

  • Nested Submenus: The "File" menu contains an "Open Recent" submenu, and the "View" menu contains a "Zoom" submenu. These should open secondary dropdown lists when activated.
  • Disabled Menu Items: The "File" menu contains a disabled "Print" item, and the "View" menu contains a disabled but checked "Show Comments" item.
  • Single Checkable Items (Radio behavior): The "Zoom" submenu under "View" has mutually exclusive options. Like radio buttons, checking one should deselect all others. '100%' is initially checked.
  • Multiple Checkable Items (Checkbox behavior): The last three items in the "View" menu are checkable. They should behave like checkboxes where multiple items can be toggled on or off independently, except for the aforementioned "Show Comments", which is checked by default and not modifiable by the user.
  • Separators: Some menus use horizontal lines (<hr> elements) to visually group related items. There are 2 separators in the "File" menu, 1 in the "Open Recent" submenu, 1 in the "Edit" menu, and 1 in the "View" menu.
